# Velvet-website
Velvet

About the Project

Velvet is a web-based platform designed to make engineering admission and college cutoff information easier to explore.

The main idea is to bring information such as CET ranks, previous-year cutoffs, colleges, branches, and admission-related details into one simple and easy-to-use interface.

What the Website Currently Includes

CET Rank Check
Users can enter their rank and category to check which colleges and branches they may be eligible for based on available cutoff data.
Previous-Year Cutoffs
Users can browse engineering admission cutoffs from previous years, currently planned around the 2020–2026 period.

College Information
The platform aims to provide information about B.E./B.Tech colleges, including college codes, locations, available branches, and relevant admission details.
How It Works
The website is currently a front-end prototype.

The basic workflow is:

1. The user selects a feature.
2. The user enters or selects relevant information such as rank, category, college, or year.
3. The website processes the available cutoff information.
4. The user receives relevant college, branch, or cutoff details.

Current Status

This is an early working prototype and is still under development.

The current version mainly focuses on:

- User interface and design
- Overall website structure
- Navigation
- Feature concepts
- College and cutoff information presentation

Some data and functionality are still being developed and improved. The final version will require properly verified and structured admission/cutoff data.

Development Approach

The website was developed by defining the concept, features, layout, and functionality requirements and using an AI-assisted development environment to implement the website.

The project is currently being used as a prototype to test the idea and improve the overall experience.
